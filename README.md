💰 Finans — Personal Finance

Modern and responsive landing page for a personal finance application, developed with a focus on clean design, usability, and conversion.

📌 About the Project

Finans is a landing page created to showcase a personal financial management application. The project was built as a front-end development practice exercise, emphasizing responsive layout, visual hierarchy, and HTML/CSS best practices.

The design prioritizes clarity and conversion: users quickly understand the product’s purpose and are naturally guided toward registration.

✨ Page Features
- Hero section with call-to-action and email signup field
- Benefits sections with images and descriptive text
- Features grid with icons and descriptions
- Responsive navbar with mobile collapse menu
- Footer with navigation and social media links
- Download links for Android and iOS platforms


🛠️ Technologies Used
Technology  | Purpose
HTML5	    | Semantic page structure
CSS3	    | Custom styling and spacing
Bootstrap-4 | Responsive grid, navbar, and UI components
Font Awesome| Icons (Android, Apple, social media)

🎨 Design Decisions
- Color Palette: Yellow #ffc107 (Bootstrap Warning) as the primary color — representing energy, attention, and positive financial growth
- Typography: Clear hierarchy using display-4 in the hero section and h2/h4 in internal sections
- Responsiveness: Images hidden on mobile devices (d-none d-md-block) to prioritize textual content on smaller screens
- Spacing: Sections use padding: 60px 0 with subtle border-bottom separators for visual organization without clutter
